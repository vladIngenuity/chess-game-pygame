# ♟️ Advanced Python Chess Engine

A robust Chess application developed in Python. This project features a graphical interface, integrated strategic logic, and a user-friendly control system.

---

## 🎮 Game Modes

### 1. PvP (Player vs Player)
- Local multiplayer mode for two players on a single machine.
- Full turn-based mechanics with real-time move validation.

### 2. PvE (Player vs AI)
- Challenge a built-in Chess Bot.
- The AI evaluates the board to determine optimal moves, making it perfect for training and analysis.

## 🕹 Key Technical Features
- **Smart Move Validation:** Accurate logic for all pieces, including Pawns, Knights, and Royalty.
- **Visual Feedback:** Active highlighting of the selected piece and all its legal destination squares.
- **Game State Tracking:** Real-time detection of turn changes, Check, and Checkmate situations.
- **Interactive UI:** A responsive "click-to-move" interface built for a smooth player experience.

## ⌨️ Controls
Master the game with these quick keyboard and mouse commands:
- **LMB (Left Mouse Button):** Click to select a piece and click again to move it.
- **Z:** **Undo move.** Mistakenly moved a piece? Press `Z` to go back one step.
- **Escape (ESC):** **Main Menu.** Instantly exit the current match and return to the home screen.
- **R:** **Reset Game.** Restart the match from the beginning at any moment.

## 🛠 Tech Stack
- **Language:** Python 3.x
- **Logic:** Procedural & Object-Oriented Programming (OOP)
- **Environment:** Visual Studio 2022
